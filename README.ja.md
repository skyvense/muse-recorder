# Muse Daily Recorder

[English](README.md) · [简体中文](README.zh-CN.md) · 日本語 · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português](README.pt.md) · [Русский](README.ru.md)

**現在のバージョン：v1.14.0**

一日中ずっと録音するための Android コンパニオンアプリです。スマホはいつも持ち歩くもの。ボイスレコーダーの代わりに、録音を自動で分割し、自分のクラウドストレージへバックアップし、イベントマーカー・文字起こし・日次サマリーで「あとから探せる記録」に変えます。ケーブル転送も、ファイル紛失もありません。

Muse 自体はマイクを聞き続けることができないため、システムは3つの部分で構成されています。

1. **Android アプリ**（`MuseRecorder.apk`）：フォアグラウンドサービスで録音し、60分ごとに新しいセグメントを切り分け、完了したセグメントを自分の S3 互換ストレージへ自動アップロードします。文字起こしとサマリーは Muse 側で行います。
2. **イベントマーカー**：録音中に大切な瞬間をマーク。マーカーは音声と一緒にバケットへアップロードされます。
3. **レシーバー＋日次サマリー**：`receiver/` のスクリプトが1日分の音声とマーカーをバケットから取得し、文字起こしして、セグメントごとのテキスト・分析・日次サマリーを Supabase に保存します。

## 機能

- **分割録音＋自動アップロード** — 60分ごとに新しい .m4a セグメント（各約21 MB）を作成し、S3 互換オブジェクトストレージ（Cloudflare R2、Backblaze B2、Alibaba Cloud OSS、Tencent Cloud COS、AWS S3、Qiniu Kodo、カスタムエンドポイント。プリセット付き）へ自動アップロード。失敗したものはキューに入って自動で再試行され、アップロード待ちリストで状態を確認できます。
- **イベントマーカー** — 「会話」と「会議」のスイッチで重要な時間帯を挟み込み、日次レポートはその単位で整理されます。
- **長押しセルフノート** — 思いついたときにボタンを長押し。録音中ならその瞬間をマークし、待機中なら単独の音声メモを録音します。
- **自動スナップショット（任意・初期オフ）** — スマホを平らな状態から立てると、静かに写真を撮影（背面・前面・両方）。録音が動いている間は画面オフでも撮影できます。カメラの選択は即座に反映されます。
- **クラウドタブ** — バケットを日付ごとに閲覧：ストレージ使用量カード（R2 無料枠10 GBとの対比）、日ごとの写真/音声件数、写真サムネイルのグリッド、タップで再生できる音声リスト。
- **レポートタブ** — Supabase の日次サマリーに加え、その日の最も鮮明なスナップショットを活動時間帯ごとにまとめた約1 MBの「デイリーアクティビティシート」（各時間帯に短いキャプション付き）。
- **ダークモード** — システムに追従／常にライト／常にダーク（設定 → 言語とシステム）。
- **9言語UI** — 英語、簡体字中国語、日本語、韓国語、スペイン語、フランス語、ドイツ語、ポルトガル語、ロシア語。切り替えは即時反映。アプリ名は全言語で "Muse Daily Recorder" です。

## はじめに

### 1. S3 バケットを用意する（Cloudflare R2 の例）

1. cloudflare.com で登録し R2 を有効化します（無料枠：10 GB、ダウンロード無料。有効化時にカードを求められることがありますが、無料枠内では請求されません）。バケットを作成します（例：`recordings`）。
2. 「R2 API トークンの管理」で、**そのバケットだけに読み書きできるトークン**（Object Read & Write、バケット指定）を作成し、Access Key ID、Secret Access Key、アカウント ID を控えます（エンドポイントは `https://<AccountID>.r2.cloudflarestorage.com`）。
3. アプリで **Cloudflare R2** プリセットを選び、エンドポイントの `<AccountID>` を実際の ID に置き換え、バケット名と2つのキーを入力して保存します。

他のプロバイダーも同じ手順です（すべてプリセットあり）。Alibaba／Tencent／AWS／Qiniu は「virtual-host style」のチェックが必要、R2／B2 は不要です。Tencent のバケット名には `-APPID` サフィックスが付き、SecretId／SecretKey を使います。

### 2. インストールと日常の使い方

1. [Releases](https://github.com/skyvense/muse-recorder/releases) から APK をダウンロードし（ローリングリリース `latest` が常に最新のビルド、バージョン付きリリースは永久に保持）、スマホに送ってインストールします（個人用のサイドロードアプリなので、初回だけ「不明なソース」を許可）。旧バージョンへの上書きインストールで設定は引き継がれます。
2. アプリを開く → ⚙️ 設定：S3 を入力して保存（保存すると即アップロードが始まります）→ バックグラウンド実行を許可（電池最適化を無効化。Samsung 端末ではアプリのバッテリーを「制限なし」に）→ 録音タブに戻り、赤い丸ボタンをタップして開始します（録音中は四角になり、ライブ波形と現在のセグメントの進捗が表示されます）。
3. **アップロードは完全自動**：保留リストで各セグメントの状態が見え、アップロード中は進捗が表示され、結果は画面に残ります（失敗時はサーバーのエラーメッセージ付き）。手動の「今すぐ再試行」ボタンは、設定を変更したあと、または自動再試行が30分以上失敗し続けたときだけ現れます。
4. 右上の ⓘ ボタンから、録音・アップロード・マーカー・設定・FAQ・プライバシーのヘルプページを開けます。

マーカーは日ごとにバケットの `markers/events-<date>.jsonl` に保存されます。スイッチの状態は保持されるため、アプリを閉じて開き直してもずれることはありません。

## 日次サマリーのパイプライン（Muse 側）

```bash
# 環境変数: S3_ENDPOINT / S3_BUCKET / S3_ACCESS_KEY / S3_SECRET_KEY / S3_REGION / S3_STYLE (path|virtual)
# 任意: S3_DELETE_AFTER=1 → 取得後にクラウド側の原本を削除（文字起こしとレポートは残ります）
python3 receiver/fetch_day_from_s3.py --date 2026-10-23
python3 receiver/summarize_day.py   --date 2026-10-23
```

文字起こしは2通り：`OPENAI_API_KEY` を設定して Whisper API を使うか、`pip install faster-whisper` でローカルに無料で処理するか。Muse に報告時刻（例：毎朝7:30）を伝えれば、スケジュールジョブでパイプラインを自動実行し、チャットへ投稿できます。

## プライバシーとセキュリティ

- 音声は **自分のバケットにだけ** 送られます。経路に第三者のサーバーは入りません。
- 文字起こしは faster-whisper で **完全にローカル** に実行でき、選んだストレージ以外にデータが自分のハードウェアを離れることはありません。
- **このリポジトリに認証情報は含まれていません。** S3 のシークレットキーはスマホアプリの設定内にだけ存在し、レシーバー用スクリプトの Supabase キーはリポジトリ外のローカル env ファイルに置かれます。ストレージトークンは単一バケットに限定し、漏洩しても被害を封じ込めましょう。
- 他人の声の録音は、多くの場所で相手の同意が必要です。合法で、相手が知っている場面でのみ録音してください。

## 現実的な注意点

- **バッテリー**：一日中録音すると1時間あたり約3–6%消費します。夜間は充電しながら録音するのが理想です。「Wi-Fi のみアップロード」も選べます。
- **ストレージ**：1日あたり約500 MB。ローカルコピーはアップロード成功後にデフォルトで削除されます。クラウド側は `S3_DELETE_AFTER=1` やバケットのライフサイクルルールで直近数日分だけ残すのがおすすめです。
- **安定性**：Android はバックグラウンド録音を厳しく制限します。常駐するステータスバー通知はシステム要件であり、録音中であることの証明でもあります。

## ビルドとリリース

- `build-apk.sh` は Android SDK の build-tools で直接 APK をビルドします（リリースビルドに Gradle は不要）。
- `master` へのプッシュごとに GitHub Actions が **署名済み** APK をビルドし、同じファイルを2つのリリースに公開します：ローリングの `latest` と、バージョン付きの `vX.Y.Z` です。インストールは [Releases](https://github.com/skyvense/muse-recorder/releases) から。
- `muse-recorder.keystore` と `keystore-info.txt` は署名鍵です — **大切に保管してください**。アップグレードは同じ鍵で署名しないと上書きインストールできません。暗号化コピーは `vault/` にあります（AES-256-CBC + PBKDF2）。

## リポジトリ構成

- `app-project/`：アプリの全ソース（Java + Android フレームワーク API。S3 署名は純 Java の SigV4 実装で、AWS 公式テストベクターで検証済み）。
- `receiver/`：Muse 側パイプライン — `fetch_day_from_s3.py`（バケットから音声＋マーカー＋スナップショットを取得。Python 標準ライブラリのみ、署名は同じ公式ベクターで検証済み）、`summarize_day.py`（文字起こし＋レポート下書き）、Supabase 書き込みスクリプト、スナップショットシート生成スクリプト。`receiver/server.py` と `fetch_day_from_supabase.py` は旧 v1.0/v1.1 方式のアーカイブです。
- `docs/images/`：上で使用したデザイン画像。
- `README.<言語>.md`：本ファイルの他の8言語版。

v1.2 以降、アプリは **S3 のみ** 対応です（v1.0 の自前レシーバーと v1.1 の Supabase 直接アップロードはアプリから削除済み。スクリプトは参考用に `receiver/` に残っています）。
