# Muse Daily Recorder v1.8.2（S3 アップロード + イベントマーカー + デイリーサマリー）

[English](README.md) | [中文](README.zh-CN.md) | 日本語 | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Português](README.pt.md) | [Русский](README.ru.md)

Muse 自体はマイクを常時聴き続けることができないため、この仕組みは 3 つの部分から成ります。

1. **Android アプリ**（`MuseRecorder.apk`）：フォアグラウンドサービスで録音し、**60 分ごとに自動で分割**（.m4a、1 セグメント約 21 MB）して、完了したセグメントを自分の **S3 互換オブジェクトストレージ**へ自動アップロードします。失敗したアップロードはキューに入り再試行され、アプリ内の**アップロード待ちリスト**で確認できます。
2. **イベントマーカー**：録音中に重要な瞬間を手軽にマークできます（下記参照）。マーカーは音声と一緒にバケットへ送られます。
3. **デイリーサマリー**（Muse 側）：`receiver/fetch_day_from_s3.py` が前日の録音とマーカーをバケットから取得 → 文字起こし → Muse が日報にまとめます。

v1.2 以降、アプリは **S3 モードのみ**です（v1.0 の自前レシーバー、v1.1 の Supabase 直接アップロードは廃止。旧レシーバースクリプトは参考用に `receiver/` に残っています）。

## 1. S3 バケットを用意する（Cloudflare R2 の例）

1. cloudflare.com で登録し、R2 を有効化します（無料枠：10 GB、ダウンロード無料。有効化時にカード登録を求められる場合がありますが、無料枠内では課金されません）。バケットを作成します（例：`recordings`）。
2. 「R2 API トークンの管理」で、**そのバケットだけに読み書き権限を持つトークン**（Object Read & Write、バケット指定）を作成します。Access Key ID、Secret Access Key、Account ID を控えます（エンドポイントは `https://<AccountID>.r2.cloudflarestorage.com`）。
3. アプリで **Cloudflare R2** プリセットを選び、エンドポイント内の `<AccountID>` を実際の ID に置き換え、バケット名と 2 つのキーを入力して保存します。

他のプロバイダーも同様です（すべてアプリにプリセットがあります）：Backblaze B2、Alibaba Cloud OSS（S3 互換モード + アカウント AccessKey を使用。バケットはコンソールで作成）、Tencent Cloud COS（バケット名に `-APPID` サフィックスが必要。SecretId/SecretKey を使用）、AWS S3、Qiniu Kodo、または任意の S3 互換サービスは「カスタム」で利用できます。Alibaba/Tencent/AWS/Qiniu は「仮想ホスト形式」にチェックが必要です。R2/B2 は不要です。

> セキュリティ上の注意：Secret Key はスマートフォンアプリ内にのみ保存してください。チャットや公開の場所には絶対に貼らないでください。トークンを単一バケットに限定しておけば、万一漏洩しても影響を抑えられます。

## 2. インストールと日常の使い方

1. `MuseRecorder.apk` をスマートフォンに送ってインストールします（個人用アプリでストア未掲載のため、「不明なソース」を一度だけ許可します）。旧バージョンへの上書きインストールでは設定が保持されます。
2. アプリを開き →「⚙️ 設定」をタップして S3 情報を入力し、保存します（保存するとすぐにアップロードが走ります）→「バックグラウンド実行を許可（電池の最適化を無効化）」をタップ → 赤い丸ボタンをタップして録音を開始します（録音中は四角ボタンに変わり、下にライブ波形と現在のセグメントの残り分数が表示されます）。マイクと通知の権限を許可してください。Samsung 製端末では、アプリの電池設定を「制限なし」にすることをお勧めします。
3. **アップロードは完全自動です**：待ちリストに各セグメントの状態が表示され、アップロード中はライブ進捗が表示され、完了後や失敗後も結果が画面に残ります。失敗時はサーバーからのエラーメッセージ付きです。失敗したセグメント（例：オフライン時）はキューに残り、自動で再試行されます。手動の「今すぐ再アップロード」ボタンは、設定変更後、または自動再試行が 30 分以上失敗し続けた場合にのみ表示されます。S3 と録音の設定はデフォルトで折りたたまれています。「⚙️ 設定」をタップして展開します。
4. **言語**：設定画面上部の言語ピッカーでは、システムデフォルトに加え、英語・中国語・日本語・韓国語・スペイン語・フランス語・ドイツ語・ポルトガル語・ロシア語が選べ、即座に反映されます。アプリ名はすべての言語で常に "Muse Daily Recorder" です。
5. 右上の青い ⓘ ボタンをタップすると、内蔵ヘルプページが開きます（録音、アップロード、マーカー、設定、FAQ、プライバシー）。

## 3. イベントマーカー（日報のための「重要ポイント」付け）

- **会話スイッチ**：重要な会話が始まったらオン、終わったらオフにします。
- **会議スイッチ**：会議の前にオン、終了したらオフにします。
- **📌 セルフノートボタン**：思いついたこと、アイデア、ToDo などを長押しで記録します。録音中はその瞬間をマークするだけですが、アイドル時は単独のボイスノートとして録音されます。
- マーカーは日ごとにバケットの `markers/events-<日付>.jsonl` に保存されます。日報はマーカーで会話や会議を分割し、セルフノート付近の内容に特に注意を払います。スイッチの状態は記憶されるため、アプリを閉じて再度開いても混乱しません。

## 4. デイリーサマリー（Muse 側）

```bash
# 環境変数：S3_ENDPOINT / S3_BUCKET / S3_ACCESS_KEY / S3_SECRET_KEY / S3_REGION / S3_STYLE (path|virtual)
# オプション：S3_DELETE_AFTER=1 → 取得後にクラウド上の原本を削除（クラウド容量を節約。文字起こしとレポートは Muse 側に残ります）
python3 receiver/fetch_day_from_s3.py --date 2026-10-23
python3 receiver/summarize_day.py   --date 2026-10-23
```

文字起こしは 2 つの方法から選べます：`OPENAI_API_KEY` を設定（Whisper API）、または Muse のマシンに `pip install faster-whisper`（ローカル、無料）。その後、Muse にレポート時刻（例：毎朝 7:30）を伝えれば、自動実行してチャットに投稿するスケジュールジョブを設定します。

## 5. 現実的な注意点

- **バッテリー**：終日録音では 1 時間あたり約 3～6% を消費します。可能であれば夜間は充電しながら録音してください。「Wi-Fi のみでアップロード」オプションがあります。
- **ストレージ**：1 日あたり約 500 MB。ローカルコピーはアップロード成功後にデフォルトで削除されます。クラウド側は `S3_DELETE_AFTER=1` か、直近数日分だけ残すバケットライフサイクルルールの利用をお勧めします。
- **安定性**：Android はバックグラウンド録音を厳しく制限しています。ステータスバーへの常駐通知はシステム要件であり、録音中であることの証明でもあります。朝晩にアプリ内の「X 分間録音中」をちらっと確認すれば十分です。
- **コンプライアンス**：他者との会話の録音は、多くの地域で相手の同意が必要です。合法で、相手が知っている場面でのみ使用してください。

## 6. 構成

- `app-project/`：アプリの完全なソース（Java + Android フレームワーク API。S3 署名は純 Java 実装で、AWS 公式 SigV4 テストベクトルで検証済み）。
- `receiver/fetch_day_from_s3.py`：S3 バケットから音声とマーカーを取得します（Python 標準ライブラリのみ。署名実装も同じ公式テストベクトルに合格）。
- `receiver/summarize_day.py`：文字起こし + レポート草案。`receiver/server.py` と `fetch_day_from_supabase.py` は旧方式のアーカイブです。
- `build-apk.sh`：Android SDK build-tools を直接使って APK をビルドします。
- `.github/workflows/build.yml`：master へのプッシュごとに CI がビルドし、同じ APK を 2 つのリリースとして公開します。常に最新ビルドを指すローリング `latest` リリースと、バージョンごとに永久保存される正式リリース（タグ `vX.Y.Z`）です。最新ビルドはいつでもこちらからダウンロードできます：https://github.com/skyvense/muse-recorder/releases/tag/latest
- `muse-recorder.keystore` + `keystore-info.txt`：署名鍵 — **必ず大切に保管してください**。アップグレードは同じ鍵で署名しなければならず、そうでないと旧バージョンへの上書きインストールができません。暗号化コピーは `vault/` にあります（AES-256-CBC + PBKDF2）。
