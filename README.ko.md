# Muse Daily Recorder

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · 한국어 · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português](README.pt.md) · [Русский](README.ru.md)

**현재 버전: v1.14.0**

하루 종일 녹음하기 위한 안드로이드 컴패니언 앱입니다. 휴대폰은 항상 몸에 지니고 다니니 녹음펜을 대신합니다. 녹음은 자동으로 나뉘어 내 클라우드 스토리지에 백업되고, 이벤트 마커·전사·일일 요약 덕분에 나중에 찾고 되돌아볼 수 있는 기록이 됩니다. 케이블로 옮길 일도, 파일을 잃을 일도 없습니다.

Muse 자체는 마이크를 계속 들을 수 없기 때문에, 이 시스템은 세 부분으로 이루어져 있습니다.

1. **안드로이드 앱**(`MuseRecorder.apk`): 포그라운드 서비스로 녹음하며 60분마다 새 세그먼트를 만들고, 완성된 세그먼트를 내 S3 호환 스토리지에 자동 업로드합니다. 전사와 요약은 Muse 쪽에서 처리합니다.
2. **이벤트 마커**: 녹음 중 중요한 순간을 표시하면 마커가 오디오와 함께 버킷에 업로드됩니다.
3. **리시버 + 일일 요약**: `receiver/`의 스크립트가 하루치 오디오와 마커를 버킷에서 가져와 전사하고, 세그먼트별 전사·분석·일일 요약을 Supabase에 저장합니다.

## 기능

- **세그먼트 녹음 + 자동 업로드** — 60분마다 새 .m4a 세그먼트(약 21MB)가 생성되어 S3 호환 객체 스토리지(Cloudflare R2, Backblaze B2, Alibaba Cloud OSS, Tencent Cloud COS, AWS S3, Qiniu Kodo, 또는 임의의 사용자 지정 엔드포인트. 프리셋 포함)에 자동 업로드됩니다. 실패한 업로드는 대기열에 남아 스스로 재시도하고, 업로드 대기 목록에서 상태를 볼 수 있습니다.
- **이벤트 마커** — 대화 스위치와 회의 스위치로 중요한 구간을 감싸면 일일 리포트가 그 단위로 정리됩니다.
- **꾹 눌러 셀프 노트** — 떠오르는 생각이 있을 때 버튼을 길게 누르세요. 녹음 중이면 그 순간을 표시하고, 대기 중이면 별도의 음성 메모를 녹음합니다.
- **자동 스냅샷(선택 기능, 기본 꺼짐)** — 휴대폰을 평평한 상태에서 세우면 조용히 사진을 찍습니다(후면, 전면 또는 둘 다). 녹음이 실행 중일 때는 화면이 꺼져 있어도 촬영됩니다. 카메라 선택은 즉시 적용됩니다.
- **클라우드 탭** — 버킷을 날짜별로 탐색: 저장 용량 카드(R2 무료 등급 10GB 기준), 날짜별 사진/오디오 개수, 사진 썸네일 그리드, 탭하면 재생되는 오디오 목록.
- **리포트 탭** — Supabase의 일일 요약과 함께, 그날의 가장 선명한 스냅샷을 활동 구간별로 모은 약 1MB짜리 "하루 활동 시트"(구간마다 짧은 설명 포함)를 제공합니다.
- **다크 모드** — 시스템 설정 따르기, 항상 라이트, 항상 다크(설정 → 언어 및 시스템).
- **9개 언어 UI** — 영어, 중국어 간체, 일본어, 한국어, 스페인어, 프랑스어, 독일어, 포르투갈어, 러시아어. 전환은 즉시 적용됩니다. 앱 이름은 모든 언어에서 "Muse Daily Recorder"입니다.

## 시작하기

### 1. S3 버킷 준비하기(Cloudflare R2 예시)

1. cloudflare.com에 가입하고 R2를 활성화합니다(무료 등급: 10GB, 다운로드 무료. 활성화 시 카드를 요구할 수 있지만 무료 한도 안에서는 청구되지 않습니다). 버킷을 만듭니다(예: `recordings`).
2. "R2 API 토큰 관리"에서 **그 버킷에만 읽기·쓰기가 가능한 토큰**(Object Read & Write, 버킷 지정)을 만들고 Access Key ID, Secret Access Key, 계정 ID를 기록합니다(엔드포인트는 `https://<AccountID>.r2.cloudflarestorage.com`).
3. 앱에서 **Cloudflare R2** 프리셋을 선택하고 엔드포인트의 `<AccountID>`를 실제 ID로 바꾼 뒤 버킷 이름과 두 키를 입력하고 저장합니다.

다른 제공업체도 방식은 같습니다(모두 프리셋 포함). Alibaba/Tencent/AWS/Qiniu는 "virtual-host style" 체크가 필요하고 R2/B2는 필요 없습니다. Tencent 버킷 이름에는 `-APPID` 접미사가 붙고 SecretId/SecretKey를 사용합니다.

### 2. 설치와 일상 사용

1. [Releases](https://github.com/skyvense/muse-recorder/releases)에서 APK를 다운로드합니다(롤링 릴리스 `latest`가 항상 최신 빌드이고, 버전 릴리스는 영구 보존됩니다). 휴대폰으로 보내 설치합니다(개인용 사이드로드 앱이라 처음 한 번 "출처를 알 수 없는 앱" 허용이 필요합니다). 기존 버전 위에 설치하면 설정이 유지됩니다.
2. 앱 열기 → ⚙️ 설정: S3를 입력하고 저장(저장하면 바로 업로드가 시작됩니다) → 백그라운드 실행 허용(배터리 최적화 해제. 삼성 휴대폰에서는 앱 배터리를 "제한 없음"으로) → 녹음 탭으로 돌아와 빨간 원형 버튼을 탭해 시작합니다(녹음 중에는 사각형으로 바뀌고 실시간 파형과 현재 세그먼트 진행률이 표시됩니다).
3. **업로드는 완전 자동입니다**: 대기 목록에서 각 세그먼트의 상태를 볼 수 있고, 업로드 중에는 진행률이, 끝나면 결과가 화면에 남습니다(실패 시 서버 오류 메시지 포함). 수동 "지금 다시 업로드" 버튼은 설정을 바꾼 뒤, 또는 자동 재시도가 30분 넘게 실패했을 때만 나타납니다.
4. 오른쪽 위 ⓘ 버튼을 누르면 녹음, 업로드, 마커, 설정, FAQ, 개인정보에 대한 내장 도움말이 열립니다.

마커는 날짜별로 버킷의 `markers/events-<date>.jsonl`에 저장됩니다. 스위치 상태는 기억되므로 앱을 닫았다 열어도 흐트러지지 않습니다.

## 일일 요약 파이프라인(Muse 쪽)

```bash
# 환경 변수: S3_ENDPOINT / S3_BUCKET / S3_ACCESS_KEY / S3_SECRET_KEY / S3_REGION / S3_STYLE (path|virtual)
# 선택: S3_DELETE_AFTER=1 → 가져온 뒤 클라우드의 원본 삭제(전사와 리포트는 그대로 남음)
python3 receiver/fetch_day_from_s3.py --date 2026-10-23
python3 receiver/summarize_day.py   --date 2026-10-23
```

전사는 두 가지 중 선택: `OPENAI_API_KEY`를 설정해 Whisper API를 쓰거나, `pip install faster-whisper`로 로컬에서 무료로 전사합니다. Muse에게 리포트 시간(예: 매일 아침 7:30)을 알려주면 예약 작업이 파이프라인을 자동 실행해 채팅으로 보내줍니다.

## 개인정보와 보안

- 오디오는 **내 버킷에만** 갑니다. 과정에 제3자 서버는 없습니다.
- 전사는 faster-whisper로 **전적으로 로컬**에서 수행할 수 있어, 선택한 스토리지 외에는 데이터가 내 하드웨어를 떠날 필요가 없습니다.
- **이 저장소에는 자격 증명이 없습니다.** S3 비밀 키는 휴대폰 앱 설정 안에만 있고, 리시버 스크립트의 Supabase 키는 저장소 밖의 로컬 env 파일에 있습니다. 스토리지 토큰은 단일 버킷으로 범위를 제한해 유출 시에도 피해가 퍼지지 않게 하세요.
- 다른 사람의 목소리를 녹음하려면 많은 곳에서 상대의 동의가 필요합니다. 합법적이고 상대가 아는 상황에서만 녹음하세요.

## 현실적인 주의사항

- **배터리**: 종일 녹음은 시간당 약 3–6%를 씁니다. 밤새 충전하며 녹음하면 좋습니다. "Wi-Fi에서만 업로드"도 가능합니다.
- **저장 공간**: 하루 약 500MB. 로컬 사본은 업로드 성공 후 기본으로 삭제됩니다. 클라우드 쪽은 `S3_DELETE_AFTER=1`이나 버킷 수명 주기 규칙으로 최근 며칠치만 남기세요.
- **안정성**: 안드로이드는 백그라운드 녹음을 엄격히 제한합니다. 상태 표시줄의 상시 알림은 시스템 요구사항이며, 녹음 중이라는 증거이기도 합니다.

## 빌드와 릴리스

- `build-apk.sh`는 Android SDK build-tools로 APK를 직접 빌드합니다(릴리스 빌드에 Gradle이 필요 없습니다).
- `master`에 푸시할 때마다 GitHub Actions가 **서명된** APK를 빌드해 같은 파일을 두 릴리스에 게시합니다: 롤링 `latest`와 버전별 `vX.Y.Z`. 설치는 [Releases](https://github.com/skyvense/muse-recorder/releases)에서.
- `muse-recorder.keystore`와 `keystore-info.txt`는 서명 키입니다 — **안전하게 보관하세요**. 업그레이드는 같은 키로 서명해야 기존 버전 위에 설치할 수 있습니다. 암호화 사본은 `vault/`에 있습니다(AES-256-CBC + PBKDF2).

## 저장소 구조

- `app-project/`: 앱 전체 소스(Java + Android 프레임워크 API. S3 서명은 순수 Java SigV4 구현으로 AWS 공식 테스트 벡터로 검증됨).
- `receiver/`: Muse 쪽 파이프라인 — `fetch_day_from_s3.py`(버킷에서 오디오 + 마커 + 스냅샷 가져오기. Python 표준 라이브러리만 사용, 서명도 같은 공식 벡터로 검증됨), `summarize_day.py`(전사 + 리포트 초안), Supabase 기록 스크립트, 스냅샷 시트 생성 스크립트. `receiver/server.py`와 `fetch_day_from_supabase.py`는 옛 v1.0/v1.1 방식의 아카이브입니다.
- `docs/images/`: 위에 사용한 디자인 이미지.
- `README.<언어>.md`: 이 파일의 다른 8개 언어 버전.

v1.2부터 앱은 **S3 전용**입니다(v1.0의 자체 호스팅 리시버와 v1.1의 Supabase 직접 업로드는 앱에서 제거됐고, 스크립트는 참고용으로 `receiver/`에 남아 있습니다).
