# Muse Daily Recorder

**Текущая версия: v1.14.0**

Приложение-компаньон для Android, созданное для записи в течение всего дня. Телефон всегда с вами, поэтому он заменяет диктофон-ручку: записи автоматически делятся на сегменты, резервируются в ваше собственное облачное хранилище и — с метками событий, транскриптами и ежедневной сводкой — превращаются в то, что действительно можно искать и пересматривать. Никаких кабелей и потерянных файлов.

Сам Muse не может непрерывно слушать микрофон, поэтому система состоит из трёх частей:

1. **Приложение Android** (`MuseRecorder.apk`): рекордер с foreground-службой, который каждые 60 минут нарезает новый сегмент и автоматически загружает каждый готовый сегмент в ваше собственное S3-совместимое хранилище. Транскрипция и сводки выполняются на стороне Muse.
2. **Метки событий**: отмечайте важные моменты прямо во время записи; метки загружаются в бакет вместе с аудио.
3. **Приёмник + ежедневная сводка**: скрипты из `receiver/` скачивают аудио и метки за день из бакета, транскрибируют их и сохраняют в Supabase транскрипты по сегментам, анализы и ежедневную сводку.

## Возможности

- **Сегментная запись + автоматическая загрузка** — новый сегмент .m4a каждые 60 минут (около 21 МБ каждый), автоматическая загрузка в S3-совместимое объектное хранилище (Cloudflare R2, Backblaze B2, Alibaba Cloud OSS, Tencent Cloud COS, AWS S3, Qiniu Kodo или любой собственный endpoint; пресеты встроены). Неудачные загрузки встают в очередь и повторяются сами; список ожидающих загрузок показывает, что ещё не отправлено.
- **Метки событий** — переключатели «Разговор» и «Совещание» обрамляют важное; ежедневный отчёт организует содержимое по ним.
- **Заметки для себя по долгому нажатию** — удерживайте кнопку, когда что-то приходит в голову; во время записи это отмечает момент, в простое — записывает отдельную голосовую заметку.
- **Автоснимок (опционально, по умолчанию выключено)** — поднимите телефон из горизонтального положения в вертикальное, и он тихо сделает фото (задняя, фронтальная или обе камеры). Пока идёт запись, снимки работают и при выключенном экране. Выбор камеры применяется сразу.
- **Вкладка «Облако»** — просмотр бакета по датам: карточка использования хранилища (на фоне бесплатных 10 ГБ R2), счётчики фото и аудио за день, сетка миниатюр фото и аудио, которое воспроизводится одним касанием.
- **Вкладка «Отчёты»** — ежедневные сводки из Supabase и для каждого дня «лист активности дня»: коллаж примерно на 1 МБ из самых чётких снимков дня, сгруппированных по периодам активности, с короткой подписью к каждому периоду.
- **Тёмная тема** — следовать системе, всегда светлая или всегда тёмная (Настройки → Язык и система).
- **Интерфейс на 9 языках** — английский, упрощённый китайский, японский, корейский, испанский, французский, немецкий, португальский, русский; переключение применяется сразу. Название приложения во всех языках — «Muse Daily Recorder».

## Начало работы

### 1. Подготовьте S3-бакет (на примере Cloudflare R2)

1. Зарегистрируйтесь на cloudflare.com и включите R2 (бесплатный тариф: 10 ГБ, скачивание бесплатно; при активации может потребоваться карта, но в пределах бесплатной квоты ничего не списывается). Создайте бакет, например `recordings`.
2. В разделе «Manage R2 API Tokens» **создайте токен с доступом на чтение и запись только к этому бакету** (Object Read & Write, ограничен бакетом). Запишите Access Key ID, Secret Access Key и ваш Account ID (endpoint — `https://<AccountID>.r2.cloudflarestorage.com`).
3. В приложении выберите пресет **Cloudflare R2**, замените `<AccountID>` в endpoint на ваш настоящий ID, введите имя бакета и оба ключа, затем сохраните.

Другие провайдеры работают так же (у всех есть пресеты в приложении). Для Alibaba/Tencent/AWS/Qiniu нужно отметить «virtual-host style»; для R2/B2 — нет. Имена бакетов Tencent имеют суффикс `-APPID` и используют SecretId/SecretKey.

### 2. Установка и повседневное использование

1. Скачайте APK из [Releases](https://github.com/skyvense/muse-recorder/releases) (скользящий релиз `latest` всегда содержит самую свежую сборку; версионные релизы хранятся навсегда), отправьте его на телефон и установите (это персональное приложение с ручной установкой, поэтому один раз разрешите «неизвестные источники»). Установка поверх старой версии сохраняет настройки.
2. Откройте приложение → ⚙️ Настройки: заполните S3 и сохраните (сохранение сразу запускает загрузку) → разрешите работу в фоне (отключите оптимизацию батареи; на телефонах Samsung также поставьте батарее приложения «Без ограничений») → вернитесь на вкладку записи и нажмите красную круглую кнопку (во время записи она становится квадратом, с живой волной и прогрессом текущего сегмента).
3. **Загрузки полностью автоматические**: список ожидания показывает состояние каждого сегмента, во время загрузки виден живой прогресс, а результат остаётся на экране после — при ошибке с сообщением от сервера. Ручная кнопка «повторить сейчас» появляется только после изменения настроек или после более чем 30 минут неудачных автоматических повторов.
4. Кнопка ⓘ в правом верхнем углу открывает встроенную справку (запись, загрузка, метки, настройки, FAQ, конфиденциальность).

Метки хранятся по дням в бакете в файле `markers/events-<date>.jsonl`. Состояния переключателей запоминаются, поэтому закрытие и повторное открытие приложения ничего не сбивает.

## Конвейер ежедневной сводки (сторона Muse)

```bash
# Переменные окружения: S3_ENDPOINT / S3_BUCKET / S3_ACCESS_KEY / S3_SECRET_KEY / S3_REGION / S3_STYLE (path|virtual)
# Необязательно: S3_DELETE_AFTER=1 → удалять оригиналы из облака после скачивания (транскрипты и отчёты остаются)
python3 receiver/fetch_day_from_s3.py --date 2026-10-23
python3 receiver/summarize_day.py   --date 2026-10-23
```

Транскрипция — два варианта: задать `OPENAI_API_KEY` (API Whisper) или `pip install faster-whisper` и транскрибировать локально и бесплатно. Назовите Muse время отчёта (например, каждое утро в 7:30), и запланированное задание сможет автоматически запускать конвейер и публиковать отчёт в чат.

## Конфиденциальность и безопасность

- Аудио уходит **только в ваш собственный бакет** — никаких сторонних серверов в цепочке.
- Транскрипция может выполняться **полностью локально** (faster-whisper); данные не покидают ваше оборудование, кроме выбранного вами хранилища.
- **В этом репозитории нет никаких учётных данных.** Секретный ключ S3 существует только в настройках приложения на телефоне; ключи Supabase приёмных скриптов лежат в локальных env-файлах вне репозитория. Ограничивайте токены хранилища одним бакетом, чтобы утечка оставалась локальной.
- Запись других людей во многих местах требует их согласия — записывайте только там, где это законно и где другая сторона в курсе.

## Трезвый взгляд

- **Батарея**: запись в течение дня расходует примерно 3–6% в час; по возможности записывайте ночью на зарядке. Доступна опция «загрузка только по Wi-Fi».
- **Хранилище**: около 500 МБ в день. Локальные копии по умолчанию удаляются после успешной загрузки; для облака используйте `S3_DELETE_AFTER=1` или правило жизненного цикла бакета, сохраняющее только последние несколько дней.
- **Стабильность**: Android строго ограничивает фоновую запись; постоянное уведомление в строке состояния — требование системы (и одновременно ваше доказательство, что запись идёт).

## Сборка и релизы

- `build-apk.sh` собирает APK напрямую инструментами Android SDK build-tools (для релизной сборки Gradle не нужен).
- Каждый push в `master` запускает GitHub Actions, который собирает **подписанный** APK и публикует два релиза с одним и тем же файлом: скользящий `latest` и версионный `vX.Y.Z`. Установка — из [Releases](https://github.com/skyvense/muse-recorder/releases).
- `muse-recorder.keystore` + `keystore-info.txt` — это ключ подписи, **берегите их**. Обновления должны быть подписаны тем же ключом, иначе они не установятся поверх старой версии. Зашифрованные копии лежат в `vault/` (AES-256-CBC + PBKDF2).

## Структура репозитория

- `app-project/`: полный исходный код приложения (Java + API фреймворка Android; подпись S3 — чистая Java-реализация SigV4, проверенная на официальных тестовых векторах AWS).
- `receiver/`: конвейер на стороне Muse — `fetch_day_from_s3.py` (скачивает аудио + метки + снимки из бакета; только стандартная библиотека Python, подпись проверена теми же официальными векторами), `summarize_day.py` (транскрипция + черновик отчёта), скрипты записи в Supabase и генераторы листов снимков. `receiver/server.py` и `fetch_day_from_supabase.py` — архивы старого подхода v1.0/v1.1.
- `docs/images/`: дизайн-изображения, использованные выше.
- `README.<язык>.md`: этот файл на остальных 8 языках.

С версии v1.2 приложение работает **только с S3** (собственный приёмник из v1.0 и прямая загрузка в Supabase из v1.1 удалены из приложения; скрипты остались в `receiver/` для справки).
