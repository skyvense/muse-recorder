# Muse Daily Recorder v1.8.2 (загрузка в S3 + маркеры событий + ежедневная сводка)

[English](README.md) | [中文](README.zh-CN.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Português](README.pt.md) | Русский

Сам Muse не может слушать микрофон непрерывно, поэтому решение состоит из трёх частей:

1. **Android-приложение** (`MuseRecorder.apk`): запись через foreground-сервис, который **нарезает новый сегмент каждые 60 минут** (.m4a, ~21 МБ на сегмент) и автоматически загружает каждый готовый сегмент в ваше собственное **S3-совместимое объектное хранилище**. Неудачные загрузки ставятся в очередь и повторяются; в приложении есть **список ожидающих загрузок**.
2. **Маркеры событий**: отмечайте важные моменты во время записи (см. ниже); маркеры загружаются в бакет вместе со звуком.
3. **Ежедневная сводка** (на стороне Muse): `receiver/fetch_day_from_s3.py` забирает из бакета записи и маркеры за предыдущий день → расшифровывает → Muse превращает их в ежедневный отчёт.

Начиная с v1.2 приложение работает **только с S3** (самостоятельный приёмник из v1.0 и прямая загрузка в Supabase из v1.1 удалены; старые скрипты приёмника сохранены в `receiver/` для справки).

## 1. Подготовка S3-бакета (на примере Cloudflare R2)

1. Зарегистрируйтесь на cloudflare.com и включите R2 (бесплатный тариф: 10 ГБ, скачивание бесплатно; при активации может потребоваться карта, но в пределах бесплатной квоты ничего не списывается). Создайте бакет, например `recordings`.
2. В разделе «Управление API-токенами R2» **создайте токен с правами чтения и записи только для этого бакета** (Object Read & Write, с ограничением бакетом). Запишите Access Key ID, Secret Access Key и ваш Account ID (эндпоинт: `https://<AccountID>.r2.cloudflarestorage.com`).
3. В приложении выберите предустановку **Cloudflare R2**, замените `<AccountID>` в эндпоинте на ваш реальный ID, заполните имя бакета и оба ключа, затем сохраните.

Другие провайдеры работают так же (для всех есть предустановки в приложении): Backblaze B2, Alibaba Cloud OSS (используйте S3-совместимый режим + AccessKey аккаунта; бакет создаётся в консоли), Tencent Cloud COS (имена бакетов содержат суффикс `-APPID`; используйте SecretId/SecretKey), AWS S3, Qiniu Kodo или любой S3-совместимый сервис через «Пользовательский». Для Alibaba/Tencent/AWS/Qiniu нужно включить «стиль виртуального хоста»; для R2/B2 — нет.

> Замечание о безопасности: Secret Key живёт только в приложении на телефоне — никогда не вставляйте его в чат или в публичные места. Ограничение токена одним бакетом уменьшает ущерб в случае утечки.

## 2. Установка и повседневное использование

1. Отправьте `MuseRecorder.apk` на телефон и установите его (личное приложение, не опубликованное в магазине, поэтому один раз разрешите «неизвестные источники»). Установка поверх старой версии сохраняет ваши настройки.
2. Откройте приложение → нажмите «⚙️ Настройки», заполните данные S3 и сохраните (при сохранении сразу запустится загрузка) → нажмите «Разрешить работу в фоне (отключить оптимизацию батареи)» → нажмите красную круглую кнопку, чтобы начать запись (во время записи она превращается в квадрат, под ней — живая осциллограмма и оставшиеся минуты текущего сегмента), и выдайте разрешения на микрофон и уведомления. На телефонах Samsung дополнительно переведите батарею приложения в режим «Без ограничений».
3. **Загрузки полностью автоматические**: список ожидания показывает состояние каждого сегмента, во время загрузки виден живой прогресс, а результат остаётся на экране после — с сообщением об ошибке сервера в случае сбоя. Сегменты, потерпевшие неудачу (например, без сети), остаются в очереди и повторяются автоматически. Кнопка «повторить загрузку сейчас» вручную появляется только после изменения настроек или после 30+ минут неудачных автоматических повторов. Настройки S3 и записи по умолчанию свёрнуты; нажмите «⚙️ Настройки», чтобы развернуть их.
4. **Язык**: переключатель в верхней части настроек предлагает системный язык плюс английский, китайский, японский, корейский, испанский, французский, немецкий, португальский и русский и применяется сразу. Название приложения на всех языках всегда «Muse Daily Recorder».
5. Синяя кнопка ⓘ в правом верхнем углу открывает встроенную страницу помощи (запись, загрузка, маркеры, настройки, FAQ, конфиденциальность).

## 3. Маркеры событий (выделение главного для ежедневного отчёта)

- **Переключатель разговора**: включите его, когда начинается важный разговор, и выключите, когда он закончится.
- **Переключатель встречи**: включите его перед встречей и выключите, когда она завершится.
- **Кнопка 📌 личной заметки**: удерживайте её, когда вам что-то приходит в голову — идея, задача, мысль. Во время записи она просто отмечает момент; в покое — записывает отдельную голосовую заметку.
- Маркеры хранятся по дням в бакете по пути `markers/events-<дата>.jsonl`; ежедневный отчёт делит разговоры и встречи по маркерам и уделяет особое внимание содержимому рядом с личными заметками. Состояния переключателей запоминаются, поэтому закрытие и повторное открытие приложения никогда их не сбивает.

## 4. Ежедневная сводка (на стороне Muse)

```bash
# Переменные окружения: S3_ENDPOINT / S3_BUCKET / S3_ACCESS_KEY / S3_SECRET_KEY / S3_REGION / S3_STYLE (path|virtual)
# Опционально: S3_DELETE_AFTER=1 → удалить облачные оригиналы после скачивания (экономит место в облаке; расшифровки и отчёты остаются на стороне Muse)
python3 receiver/fetch_day_from_s3.py --date 2026-10-23
python3 receiver/summarize_day.py   --date 2026-10-23
```

Расшифровка — два варианта: установите `OPENAI_API_KEY` (Whisper API) или выполните `pip install faster-whisper` на машине Muse (локально, бесплатно). Затем сообщите Muse время отчёта (например, 7:30 каждое утро), и он настроит запланированное задание, которое будет запускаться само и публиковать отчёт в чат.

## 5. Реалистичные напоминания

- **Батарея**: круглосуточная запись расходует примерно 3–6% в час; по возможности записывайте, пока телефон ночью заряжается. Есть опция «загрузка только по Wi-Fi».
- **Хранилище**: около 500 МБ в день. Локальные копии по умолчанию удаляются после успешной загрузки; для облака используйте `S3_DELETE_AFTER=1` или правило жизненного цикла бакета, хранящее только последние дни.
- **Стабильность**: Android строго ограничивает фоновую запись; постоянное уведомление в строке состояния — требование системы (а также ваше доказательство того, что запись идёт). Быстрого взгляда утром и вечером на «записывается уже X минут» в приложении достаточно.
- **Соблюдение правил**: запись разговоров с другими людьми во многих местах требует их согласия — используйте только там, где это законно и где другая сторона в курсе.

## 6. Структура

- `app-project/`: полный исходный код приложения (Java + API фреймворка Android; подпись S3 — чистая Java-реализация, проверенная официальными тестовыми векторами AWS SigV4).
- `receiver/fetch_day_from_s3.py`: забирает аудио и маркеры из S3-бакета (только стандартная библиотека Python; реализация подписи прошла те же официальные векторы).
- `receiver/summarize_day.py`: расшифровка + черновик отчёта; `receiver/server.py` и `fetch_day_from_supabase.py` — архивы старого подхода.
- `build-apk.sh`: собирает APK напрямую с помощью build-tools из Android SDK.
- `.github/workflows/build.yml`: CI собирает при каждом пуше в master и публикует два релиза с одним и тем же APK — скользящий релиз `latest` (всегда новейшая сборка) и версионный релиз для каждой версии (тег `vX.Y.Z`, хранится вечно). Новейшую сборку всегда можно скачать здесь: https://github.com/skyvense/muse-recorder/releases/tag/latest
- `muse-recorder.keystore` + `keystore-info.txt`: ключ подписи — **берегите его**. Обновления должны подписываться тем же ключом, иначе их нельзя будет установить поверх старой версии. Зашифрованные копии лежат в `vault/` (AES-256-CBC + PBKDF2).
