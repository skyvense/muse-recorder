🎙 Muse Recorder · Help

Recording

  • Tap the big red round button to start recording; while recording it becomes a red square — tap again to stop.
  • Recordings are split into segments (60 minutes by default). The status line shows “X min left · Y min recorded”.
  • Recording runs in a foreground service, so switching apps or locking the screen never stops it; a persistent notification shows while recording.
  • With “Auto-resume after restart” on, recording resumes automatically after the phone reboots.

Upload (fully automatic)

  • Each finished segment uploads immediately; failures retry every minute; saving settings triggers an upload right away.
  • A manual “Retry upload now” button only appears after a settings change without a successful upload, or after 30+ minutes of continuous failure.
  • Files land in your bucket by day: <date>/rec_….m4a; event markers go to markers/events-<date>.jsonl; voice notes are filed by date the same way.
  • At 48 kbps the quality is plenty for transcription: about 21 MB per hour, ~0.5 GB per day.

Event markers (bottom bar)

  • 💬 Conversation / 👥 Meeting: tap once to start (the card changes color and shows elapsed minutes), tap again to stop. Markers are written to the day’s marker file and used to structure the transcription summary.
  • 🎙 Voice note: hold to talk, release to stop. While recording it only writes a start/end marker pair; when idle, holding records a standalone voice-note clip that uploads like any other segment.

Settings (⚙️ button)

  • Pick a cloud preset first (Cloudflare R2 by default) — it fills in the endpoint and region, which you can still edit by hand.
  • Endpoint: for R2 use https://<AccountID>.r2.cloudflarestorage.com (the https:// prefix is added automatically if you omit it).
  • Region: R2 uses auto; other providers use their region code.
  • Bucket: Tencent Cloud bucket names need the -APPID suffix.
  • Virtual-host style: check it for providers that put the bucket in the hostname (Alibaba / Tencent / AWS / Qiniu); leave it off for R2 / B2.
  • Access Key / Secret live only on this phone — never share them. A wrong secret shows up as the server’s error in the upload status line.
  • Segment length defaults to 60 minutes; “Wi‑Fi only upload” is for metered connections; “Delete local segments after upload” saves phone storage.
  • If notifications or background recording get killed by the system, use “Allow background running” to whitelist the app in battery settings.
  • Language: at the top of Settings you can pick a language or follow the system language; the app restarts its UI in the new language immediately.

Common issues

  • Uploads keep failing: read the server error in the status line first, then double-check endpoint, region, bucket and keys. With R2 the usual cause is a wrong bucket name or Account ID.
  • Files still pending: they retry automatically every minute; after 30 minutes of continuous failure a manual retry button appears.
  • Switching phones / reinstalling: the new APK must be signed with the same keystore to install over the old version — keep your signing key backed up before moving devices.
⚠️ Privacy: when a recording includes other people’s conversation, get their consent first. Recordings only go to the storage bucket you configured — never to any third party.
