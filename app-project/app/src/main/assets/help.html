🎙 Muse 录音助手 · 使用帮助

录音

  • 点顶部红色圆按钮开始录音，录音中按钮变成红色方块，再点一次停止。
  • 录音按段切分（默认每段 60 分钟），状态行显示「剩余 X 分钟 · 已录 Y 分钟」。
  • 录音在前台服务里进行，切换到别的 App、锁屏都不会停；通知栏有正在录音的提示。
  • 打开「手机重启后自动恢复录音」后，开机也会自动续录。

上传（全自动，不用管）

  • 每段录完立刻上传；上传中途失败会每分钟自动重试；改完配置保存后也会立刻传一次。
  • 只有连续失败超过半小时，才会出现「立即重试上传」手动按钮。
  • 录音按天存进存储桶：<日期>/rec_….m4a；事件标记在 markers/events-<日期>.jsonl 里；自述录音同样按日期归档。
  • 码率 48 kbps，音质够转写用，每小时约 21 MB，一天约 0.5 GB。

事件标记（底部固定栏）

  • 💬 对话 / 👥 会议：点一下开始（卡片变色并显示已进行分钟数），再点一下结束。标记会写进当天的标记文件，转写总结时会按标记分段。
  • 🎙 自述录音：按住说话、松开结束。正在录音时只记一对开始/结束标记；没在录音时按住，会单独录一段自述音频并上传。

自动拍照（抬起手机触发）

  • 在配置里勾选「抬起手机自动拍照」开启，默认关闭，第一次开启会请求相机权限。开关和摄像头选项（前后都拍 / 只后置 / 只前置）都是改完立即生效，不用等保存。配置区还有「立即测试拍一次」按钮，可以先验证相机是否工作。
  • 触发方式：把手机从放低（角度小于 60°）抬到接近直立（72°–108°，接近 90°）并停稳约半秒，随后按所选摄像头拍照；每真正拍到一张，手机会轻震一下（震动 = 拍到了）。
  • 锁屏、息屏也能拍：前提是录音正在运行（录音服务会带上相机类型，这是系统允许后台开相机的正规方式）。手机重启后录音若自动恢复，息屏拍照要等你打开一次 App 才会生效。没在录音时，只有亮屏状态能触发。
  • 照片和录音一样排队自动上传，存到桶里的 snapshot-日期/ 文件夹；文件列表里也能看到待上传的快照。
  • 防误触：拍完后必须把手机放平重新“上膛”才会再触发，且两次触发至少间隔 15 秒。录音运行期间（或 App 打开时）有效；不想要时在配置里关掉，App 就完全不用摄像头。

配置（⚙️ 配置按钮）

  • 先选云厂商预置（默认 Cloudflare R2），会自动填好地址和区域，再按需手改。
  • Endpoint：R2 填 https://<AccountID>.r2.cloudflarestorage.com（不写 https:// 也会自动补）。
  • 区域 Region：R2 填 auto，其他厂商填对应的区域代号。
  • 存储桶 Bucket：腾讯云的桶名要带 -APPID 后缀。
  • 虚拟主机风格：桶名放域名前面的厂商（阿里 / 腾讯 / AWS / 七牛）勾选，R2 / B2 不勾。
  • Access Key / Secret 只存在本机，不要发给任何人；Secret 输错会在上传状态行里看到服务器返回的错误。
  • 每段时长默认 60 分钟；「仅在 Wi‑Fi 时上传」适合流量敏感时打开；「上传成功后删除本地片段」可以省手机空间。
  • 如果通知或后台录音被系统杀掉，点「允许后台运行（关闭电池优化）」去系统设置里放行。

常见问题

  • 上传状态一直失败：先看状态行里的服务器错误文案，再核对 Endpoint、区域、桶名和密钥；R2 常见原因是桶名或 AccountID 写错。
  • 待上传列表里还有文件：等一分钟自动重试，或等它在持续失败半小时后出现手动重试按钮。
  • 换手机 / 重装：旧版 App 的签名密钥必须一致才能覆盖安装，备份好签名密钥再换设备。
⚠️ 隐私提醒：录音涉及他人对话时，请先征得对方同意。录音文件只上传到你自己配置的存储桶，不会发给任何第三方。
